Errata — Major Public-Record Changes

Editorial transparency record

This page is the index of major changes to this website's contents that have been made publicly visible since launch — primarily privacy redactions, factual corrections to published material, and material content replacements that visitors should know about. Minor typo fixes, formatting tweaks, and routine updates are intentionally omitted to keep this index useful.

For the full, byte-level change history, the deployed static HTML of each language is stored in a public GitHub repository:

  • English (this site): https://github.com/ecthrwatch/www.ecthrwatch.org
  • French: https://github.com/ecthrwatch/fr.ecthrwatch.org
  • Chinese: https://github.com/ecthrwatch/zh.ecthrwatch.org

Anyone can clone those repositories and use git log to inspect every commit. Where the public record has been deliberately edited (e.g., to remove a private email address that was inadvertently leaked into a URL), that fact is documented in the corresponding entry below — so the omission itself remains transparent.

Click any entry below for the full details.

  • 2026-09-02 — Unauthorized note removed from the Jean-Christophe Voyer email page

    Eight minutes after the Jean-Christophe Voyer email page first went live, I noticed a sentence had been inserted into it that I never wrote or approved, and that is factually wrong. It has been removed from all four language editions.

  • 2026-05-20 — Featured image corrected — AI-altered text removed (lawyer-wife entry)

    ChatGPT, while assembling the entry's featured image from earlier components, altered a piece of text inside the image without authorization. The altered text introduced a factual misattribution. The image was replaced with the originally-intended version; this page documents the chain of events in detail so the same kind of error is easier to spot — and easier to avoid — next time.

  • 2026-05-18 — Private email username removed from URL history

    A backend-data migration briefly embedded the local-part of one personal email address into a `/people/` and `/parties/` URL slug. Slug renamed in source; deploy repositories' git history rewritten to remove the string from every commit.
